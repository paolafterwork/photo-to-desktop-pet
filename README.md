# Photo to Desktop Pet｜照片变桌面宠物 🐈

给 Codex **一张宠物正面照＋一个名字**，让它制作动画、检查并修正问题。**你确认完整动态预览后，才会创建或更新宠物、设为当前伙伴。** 不需要写代码。

## 怎么使用

1. 在 Codex 里发送：

   > 请安装 https://github.com/paolafterwork/photo-to-desktop-pet 仓库中的 skills/photo-to-desktop-pet，并检查所需的 Pets 和图像生成功能。

2. 安装完成后，上传清晰的宠物正面照，再发送：

   > 使用 $photo-to-desktop-pet，把照片里的宠物做成我的桌面迷你伙伴，名字叫「黄虎」。

3. 查看形象和完整动态预览。需要修改就直接说，例如“眼睛颜色不对”“抬爪时多出了一条腿”。Codex 会修正，再给你看新版。
4. 满意后回复：**“确认动态形象，继续创建并设为当前伙伴。”**

## 流程

照片＋名字 → 主形象 → 动画制作与检查 → 修正 → **用户确认动态预览** → 创建或更新 → 选中伙伴 → 检查桌面显示。

每次修改动画后，都需要重新确认。确认前不会上传、替换已有宠物或切换当前伙伴。检查覆盖缺帧、透明背景、裁切、外形变化、身体结构、动作衔接、方向及工具错误等；自动检查无法保证发现所有问题，因此请认真看预览。

## 使用前须知

- 需要支持 Skills、图像生成和 **Pets 插件及其 create-pet/update-pet 技能**的 Codex 环境；本项目是流程 skill，不是独立桌面软件。安装后未识别时，可新开聊天或重启 Codex。
- 首次使用可能需要你连接插件或确认必要权限；其余技术步骤交给 Codex。
- **桌面显示需要单独开启。** 若客户端提供可操作的设置，Codex 会帮你设置；若不允许操作，则会指导你手动开启。“已选中”不代表桌面显示开关已经打开。
- 制作文件可保存在本地。若底层工作流要求 Library 而当前不可用，会先征得改存本地的同意。确认后的精灵图会上传至 Pets 服务，不会自动公开分享照片或宠物。
